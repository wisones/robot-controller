# 智科云底盘集成喷雾控制系统 — 开发全记录

## 1. 项目目标
基于上海智科云机器人底盘，开发一套 Windows 端图形控制软件，实现：
- **地图可视化**：获取并显示底盘建好的静态地图，叠加激光点云。
- **实时定位**：在地图上实时显示机器人位置与朝向（红色箭头）。
- **顺序导航**：在地图上点击多个目标点，机器人依次前往，并支持自动跳过失败点。
- **喷雾控制**：通过 WiFi 继电器控制左右两侧电机泵的开关与无级调速（PWM）。
- **状态监控**：显示底盘连接状态、电池电压、底盘实时运动速度。

## 2. 硬件组成
- **机器人底盘**：智科云导航底盘（IP：`192.168.10.159`，端口：`10000`），提供 TCP 协议接口。
- **喷雾执行**：12V 电机泵 ×2、药箱 x2、XY-MOS 功率模块 ×2、12V 锂电池 x2、可充电锂离子电池5v输出。
- **无线控制**：ESP8266 (NodeMCU，自带WIFI模块) 连接到底盘 AP热点，驱动两路 MOS 模块，进而水泵开关。
- **操作电脑**：Windows 笔记本(或触摸工控机、台式机），连接底盘AP热点，运行 Python/PyQt5 控制程序。

## 4. 开发历程与关键问题解决

### 4.1 环境搭建 （建议采用anaconda搭建虚拟环境）
- **目标**：在 VS Code 中建立 PyQt5 开发环境，能运行基础窗口。
- **问题**：
  - Miniconda 与 venv 冲突导致 `pyqt5-tools` 安装失败。
  - `ModuleNotFoundError: No module named 'PyQt5'`。
- **解决**：
  - 改用 conda 创建专用环境：`conda create -n robot_env python=3.10`，激活后 `conda install pyqt=5`。
  - VS Code 中手动选择解释器指向 `robot_env`。

### 4.2 图形界面搭建
- **目标**：设计主窗口布局，左侧地图区，右侧控制面板（连接、地图、导航、喷雾）。
- **实现**：使用 `QSplitter`、`QGroupBox`、`QPushButton`、`QSlider` 等控件。
- **问题**：运行时提示 `ModuleNotFoundError: No module named 'src'`。
- **解决**：将所有交叉导入改为相对导入（如 `from map_widget import MapWidget`），运行命令改为 `python src/main.py`。

### 4.3 底盘 TCP 通信
- **目标**：建立与底盘的 TCP 长连接，实现协议封包/解包和心跳维持。
- **实现**：编写 `tcp_client.py`，继承 `QObject`，使用 `pyqtSignal` 传递数据。
- **问题**：
  - 初次扫描端口时，`nmap` 发现两个开放端口 `10000` 和 `11311`。
  - 测试后确定 `10000` 为导航通信端口。
  - 程序早期出现 `AttributeError: 'MainWindow' object has no attribute 'tcp_client'`，因忘记初始化客户端。
- **解决**：在 `MainWindow.__init__` 中初始化 `self.tcp_client = RobotTCPClient()` 并连接信号。

### 4.4 地图获取与显示
- **目标**：从底盘获取静态地图并显示在界面上。
- **实现**：顺序发送 `CMD_GET_CURRENT_MAP_CONFIG` → `CMD_GET_MAP_META_DATA` → `CMD_GET_MAP_DATA`，将 Base64 图片数据解码为 `QPixmap`。
- **问题**：地图加载后位置与点云不重合。
- **解决**：使用地图元数据中的 `ORIGIN_X`、`ORIGIN_Y`、`RESOLUTION` 建立世界坐标到像素的映射公式，并在 `paintEvent` 中统一缩放和偏移。

### 4.5 激光点云实时可视化
- **目标**：订阅激光扫描，以绿色点云形式实时显示，与地图背景重合。
- **实现**：发送 `CMD_SUB_SCAN`，解析 `LASER_SCAN` 的 float 数组 (x,y,z)，直接作为世界坐标绘制。
- **问题**：最初叠加机器人位姿后点云乱飘。
- **解决**：底盘发布的 `LASER_SCAN` 已是世界坐标系，取消机器人位姿转换即可稳定重合。

### 4.6 机器人实时位置箭头
- **目标**：在地图上用红色箭头表示机器人位置和朝向。
- **问题**：箭头朝向与实际不符（指向侧面）。
- **解决**：由于屏幕Y轴与地图世界坐标Y轴相反，需要在旋转角度上补偿 `+90°`（`painter.rotate(-math.degrees(theta) + 90)`）。

### 4.7 顺序导航
- **目标**：用户点击多个目标点，机器人依次前往，到达每一目标点前原地转向下一目标点方向。
- **实现**：
  - 添加“添加目标点”、“清空目标点”、“开始顺序导航”、“停止导航”按钮。
  - 构建带朝向的目标队列：每个点根据下一个点的方向计算 `THETA`。
  - 发送 `CMD_NAV_BY_POSE2D`，底盘自动完成原地旋转+直线行走。
- **问题与解决**：
  - 早期尝试独立旋转命令 `CMD_NAV_ROTATE_TO` 一直超时，底盘不反馈完成状态 → 改用导航命令自带目标朝向方案。
  - 朝向错误：经过多次取反调整后最终使用 `math.atan2(dy, dx)` 满足要求。
  - `NAV_FAIL` 导致序列中断 → 自动跳过失败点并继续下一目标，增加连续失败次数限制。
- **导航行走转弯不顺畅（卡顿）**：
  - **现象**：执行顺序导航时，机器人前进和转弯动作非常缓慢、卡顿，甚至频繁停顿。
  - **初步怀疑**：底盘底层驱动、电机功率或导航算法异常。
  - **最终定位**：经过多次测试发现，并非软件或硬件故障，而是机器人顶部覆盖的一层防水布垂落，刚好遮挡了激光雷达的部分扫描区域。激光雷达将防水布误识别为极近距离的障碍物，导致底盘持续触发避障减速和急停。
  - **解决**：撤掉或重新固定防水布，使激光雷达视野无遮挡，机器人即刻恢复正常行走与灵活转弯。

### 4.8 喷雾控制（ESP8266 + XY-MOS）
- **目标**：通过电脑控制喷雾泵的开关与速度，不额外占用网络。
- **方案**：ESP8266 连接到底盘热点，电脑通过 TCP 发送指令。
- **问题与解决**：
  - **ESP8266 无法连接**：静态 IP 设置顺序错误，需在 `WiFi.begin()` 前调用 `WiFi.config()`。
  - **电脑无法连接**：`test_spray.py` 报 `10061 连接拒绝`，因 ESP8266 仍使用 DHCP 临时 IP。烧录修正代码后成功。
  - **喷雾按钮导致程序崩溃**：电压读取线程阻塞、滑块频繁发送命令、socket 阻塞等。最终回归基础版本，去除电压读取，仅保留非阻塞发送，滑块改用 `sliderReleased` 信号避免频繁指令。
  - **速度控制集成**：ESP8266 新增 `LEFT_SPEED`/`RIGHT_SPEED` 指令，Python 端增加 `set_left_speed` 等方法，界面增加 `QSlider`，只在释放滑块时发送一次速度值。
- **喷雾最终删除了流量控制功能**



### 4.9 底盘运动速度显示
- **目标**：在界面上实时显示底盘移动速度。
- **实现**：在 `on_pose_received` 中记录相邻两次位姿的时间差和位置差，计算 `dist/dt`，更新标签。
- **问题**：初次修改时忘记从 `pose` 中提取局部变量 `x, y`，导致 `NameError`。
- **解决**：正确提取 `x,y,theta` 后再进行速度计算。



## 5. 最终功能清单
- 底盘连接/断开、Ping 测试、版本查询
- 静态地图加载与显示
- 激光点云实时叠加（与地图重合）
- 机器人实时位置与朝向箭头
- 多目标点顺序导航
- 左右喷雾开关
- 底盘运动速度实时显示
- 电池电压显示（预留接口，当前无实际传感器）
- 水位显示

## 6. 总结
该项目从零开始，逐一克服了网络通信、坐标转换、多线程阻塞、硬件联调等问题，最终实现了高度集成、稳定可靠的底盘与喷雾控制系统。软件采用模块化设计，各功能独立且易于扩展。后续可进一步集成电压检测、路径录制、自动返回充电等功能。
