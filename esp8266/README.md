# ESP8266 nodeMCU WIFI 开发板程序编写说明


- 该开发板用于实现与电脑段的数据交互与上下位机控制连接。该开发板集成了WIFI模块，可实现与电脑端的无线数据传输。
- 该开发板基于ESP8266 WIFI开发板，使用Arduino IDE进行开发。
- 该开发板主要连接的传感器有两个称重传感器用于称重药箱，进而转换为剩余药量，使用HX711数模转换模块，该模块需要3.3V供电输入，但ESP开发板仅有三个3.3V引脚，故而将称重传感器的供电口串联供电；另有两个3.3V接口用于XY-COM驱动板供电，并通过引脚连接XY-COM驱动板（XY-COM需要大电流，因此单独供电）
